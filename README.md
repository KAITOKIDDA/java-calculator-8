### 기능 요구 사항 및 구현 목록

미션에서 제시된 기능 요구 사항을 바탕으로 구현할 기능을 상세히 정의했습니다.

* **입력 처리:** 입력 문자열이 null이거나 빈 문자열("")일 경우, 합계 0을 반환한다.
* **기본 구분자:** 쉼표(,) 또는 콜론(:)을 구분자로 사용하여 숫자를 분리하고 합산한다.
* **커스텀 구분자:** "//"와 "\n" 사이의 문자를 커스텀 구분자로 지정하여 숫자를 분리한다.
* **예외 처리:** 음수 또는 숫자가 아닌 문자가 발견될 경우, IllegalArgumentException을 발생시킨 후 애플리케이션을 종료한다.
* **출력:** 계산된 최종 합을 "결과 : [합]" 형식으로 출력한다.
